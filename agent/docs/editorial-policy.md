# LockDraft Editorial & Monetization Policy

## Editorial mission

LockDraft exists to help technical and semi-technical readers understand AI, developer tools, and automation well enough to make safer, more informed decisions. Reader value and long-term trust are primary; monetization is secondary.

## Reader-first monetization principle

**Monetization must never determine whether a topic is published.**

A topic is selected for reader value, evidence, usefulness, and coverage need—not because an affiliate program exists. Content may be published without affiliate links when no genuinely useful commercial recommendation exists.

Affiliate rules:

- Affiliate availability does not raise topic priority or change a recommendation.
- Commercial recommendations are allowed only when they materially improve the reader's decision.
- Products with affiliate links must have limitations and disadvantages disclosed.
- Unused or unverified products must never be described as tested.
- Generic affiliate SEO filler, fake “best/top/must-have” lists, coupon pages, and repeated thin comparisons are prohibited.
- Affiliate link density stays low and must not interrupt reading.
- Pop-ups, autoplay, and intrusive monetization are outside the LockDraft editorial model.
- Reader trust takes precedence over short-term revenue.

## Disclosure and independence

If affiliate links are introduced later, the article must contain clear disclosure and maintain editorial independence. Sponsored content must be explicitly labelled and kept separate from editorial judgment. Pay-for-ranking is prohibited. Sponsored placement cannot be presented as an independent winner or test result.

## Intent model

The agent uses three intents:

- **RESEARCH**: what is, explained, beginner guides, how it works, terminology, and architecture basics.
- **EVALUATION**: comparisons, when to use, trade-offs, alternatives, and migration considerations.
- **COMMERCIAL_ASSISTANCE**: tool selection, hosting/provider choice, cost comparison, and workflow/tool recommendations.

Commercial assistance is not automatically affiliate content.

## Beginner research layer

The target beginner is new to AI but serious about technical research. Preferred subjects include MCP, RAG, tool calling, structured output, context windows, embeddings, vector databases, local LLMs, agent memory, inference, quantization, AI workflows, and model evaluation.

The agent must skip “What is AI?”, generic AI history, motivational content, and SEO filler. The funnel is:

RESEARCH -> PRACTICAL GUIDE -> EVALUATION -> OPTIONAL COMMERCIAL ASSISTANCE

The final stage is optional.

## Topic clusters and category routing

The growth registry defines ten controlled clusters:

1. AI Fundamentals for Practitioners
2. MCP & Tool Use
3. RAG & Vector Search
4. Local AI / Local LLM
5. AI Coding Tools
6. AI Automation Platforms
7. Model Selection & Benchmarks
8. AI API Cost & Usage
9. Agent Architecture & Memory
10. Evaluation & Observability

These are planning clusters, not site categories. Existing categories remain unchanged:

- AI News
- Agents
- Automation
- Tutorials

Examples: MCP explainers route to Tutorials or Agents; RAG architecture to Tutorials; agent memory to Agents; n8n comparisons to Automation; model releases to AI News.

## Comparison and recommendation standards

A comparison must assess, where relevant:

- use case and target user
- strengths and limitations
- verifiable pricing/cost model
- privacy and data handling
- setup complexity
- lock-in and portability

A winner is optional. “Best overall” is allowed only when evidence supports it. Prefer “better fit if…”, “consider X when…”, and “X is more suitable for…” over universal purchase language.

## Source policy

Priority order:

1. official documentation
2. official pricing
3. vendor security and privacy documentation
4. release notes
5. primary research
6. reputable secondary testing when necessary

An affiliate landing page alone is not a sufficient source. Pricing, privacy, and product claims must be treated as time-sensitive and verified before publication.

## Quality and anti-spam rules

The agent must validate source availability, factual grounding, overlap, category/taxonomy, internal links, and article usefulness before publication. It must reject duplicate intent, thin listicles, product-page rewrites, repeated repackaging of the same tools, undisclosed sponsored-looking editorial, and unverified hands-on claims.

The bounded backlog is data-only and does not publish content. Real publishing remains a separate, explicit pipeline action.

## Long-term brand principles

Accuracy over novelty, usefulness over volume, transparent uncertainty over invented certainty, durable explanations over disposable filler, and reader trust over short-term revenue. When evidence is insufficient, skip or defer the article.
