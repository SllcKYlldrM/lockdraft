## What changed

- Environment variable `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` now caps wait times for unattended retries when quota resets are distant.
- The `claude-api` skill includes OpenTelemetry setup guidance, allowing trace routing via the `ant` CLI.
- `tool_decision` telemetry events now surface `classifier_verdict`, `permission_mode`, and `classifier_category` (the latter requires `OTEL_LOG_TOOL_DETAILS=1`), separating classifier logic from permission rules.
- Vim mode gains the `%` command for bracket navigation, compatible with delete, change, and yank operations.
- Mod inputs support a new `rows` attribute for multi-line terminal fields, where standard Enter submits and Shift+Enter or a backslash prefix inserts a line break.
- Several stability and correctness patches: quit commands preserve worktrees generated by `WorktreeCreate` hooks if unpushed commits exist; `fable` and `best` aliases retry on prior model availability instead of failing outright; Grep/Glob emit explicit errors when search binaries crash rather than masking failures as empty results; workflow agents no longer bypass steps after encountering unauthorized harness notes.
- Hook and artifact handling improved: PreToolUse restrictions on Edit/Write no longer block updates, with Claude editing then republishing autonomously; skills/commands/hooks with dense argument lists now truncate auto-completion to 64 names capped at 64 characters, preventing stalls and high memory consumption.
- Terminal rendering corrected across multiple environments: stray overlay characters on VTE < 0.53 terminals (like MATE Terminal on RHEL 8) and spurious startup text in iTerm2 are resolved. Model switches containing `application-inference-profile` no longer trigger unnecessary `awsAuthRefresh` calls or delay hooks on non-Bedrock providers. Short authentication commands no longer interrupt token refreshes, causing sudden sign-outs. Interrupted permission checks no longer misreport as user rejections, and context window downgrades avoid unsolicited summarization charges. Infinite compaction loops behind mismatched LLM gateways are halted.
- Editor behavior refined: Escape keys exit insert mode reliably on constrained systems, and free-text input fields in AskUserQuestion questions now respect vim NORMAL state, preventing accidental answer loss. Binary file reads (.xlsm, .parquet, .epub, .heic) are blocked to prevent corruption artifacts. Wide header-only markdown tables render safely, and the `/claude-api` skill accurately reflects CMEK endpoint limitations on AWS. Skills remain visible to the model following `/rewind` operations, and resumed sessions restore history navigation via ctrl+o.

## Why it matters

These changes shift Claude Code from a reactive coding assistant toward a more predictable automation layer. The new watchdog timeout prevents idle processes from blocking CI/CD pipelines or background tasks when rate limits approach. Expanded telemetry fields give engineers visibility into classifier versus permission-driven tool routing, which is essential for auditing automated decision paths. Reliability patches around hooks, workflow agents, and artifact publishing eliminate silent failure modes that previously required manual intervention. Terminal and editor corrections address long-standing friction points for developers operating in resource-constrained environments or legacy Unix terminals. For teams managing complex hook hierarchies, see our analysis of [strict hook controls and gateway filters](/posts/anthropic-releases-claude-code-v21295-with-strict-hook-controls-gateway-filters-/). Recent session stabilization efforts build on earlier work covered in [terminal layout controls and telemetry diagnostics](/posts/claude-code-update-terminal-layout-controls-telemetry-diagnostics-and-session-st/).

## What to do next

Update your local installation to capture the patched retry logic and telemetry schema. If you run Claude Code in unattended contexts, configure `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` to match your infrastructure’s tolerance for quota delays. Teams relying on structured observability should enable `OTEL_LOG_TOOL_DETAILS=1` to inspect `classifier_category` alongside verdict data. Verify that custom mods utilizing multi-line inputs align with the new `rows` parameter syntax. For organizations routing traffic through LLM proxies or deploying on restricted terminals, test the updated model-switch and compaction behaviors to confirm gateway alignment and viewport rendering. 

While the watchdog variable and telemetry enhancements improve control, auto-completion truncation remains intentional to preserve performance under heavy argument loads. Additionally, the Read tool’s binary file protection means legitimate text-based inspection of certain formats will require explicit format conversion or alternative tools.
